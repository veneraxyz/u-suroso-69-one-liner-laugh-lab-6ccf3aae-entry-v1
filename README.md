# One-Liner Laugh Lab

A robot vacuum pleads its case after eating a sock — one original funny line, at most 200 characters.

> "In my defense, the sock started it — it was lying there all soft and linty, so I did what any vacuum would do: I ate the evidence."

## How it works

`main.ts` (Node, stdlib only) writes exactly one funny line to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), guarded to a single line of 1–200 characters.
